# Smial Dol Amroth de Chile

Sitio web estático de presentación para el Smial Dol Amroth de Chile, comunidad inspirada en la obra de J. R. R. Tolkien.

## Secciones
- Inicio
- Lore
- Eventos
- Miembros
- La Sombra (minijuego narrativo colectivo; en esta primera versión es una presentación visual)
- Quiénes somos
- Registro (maqueta sin envío de datos)

## Publicación con GitHub Pages
1. En GitHub, abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama **main** y la carpeta **/(root)**.
4. Guarda y espera la publicación.

La dirección esperada será: https://heunithen.github.io/smial-dol-amroth-chile/

## Créditos y uso
Proyecto comunitario no oficial, sin afiliación con Tolkien Estate ni con titulares de derechos de autor de la obra de J. R. R. Tolkien. Las referencias a la Tierra Media se utilizan para identificar la inspiración cultural del grupo.
